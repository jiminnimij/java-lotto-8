# java-lotto-precourse

### 입력 기능
- 구입 금액 입력 
  - 비어있음/공백 제거
  - 숫자 형식 (정수)
  - 1,000원 으로 나눠떨어지지 않을 경우
- 당첨 번호 입력 (쉼표 기준으로 구분)
  - 공백 제거 후 split
  - 당첨 번호 6개 인지 검증
  - 각 숫자의 범위 검증
  - 중복 없음 검증
- 보너스 번호 입력
  - 숫자 형식 및 범위 검증
  - 당첨 번호와 중복 금지 검증

### 로또 기능
- 로또 발행
  - 입력 받은 수량만큼 로또 생성
  - 로또는 1~45 범위, 오름차순 정렬
- 당첨 여부 판단
  - 등수 규칙 정의
  - 로또 교집합 개수, 보너스 포함 여부 계산
  - rank 결정
  - 등수별 카운트

### 출력 기능
- 발행한 로또 수량 및 번호 출력
- 당첨 내역 출력
- 수익률 출력 (소수점 둘째 자리에서 반올림)
- 예외 상황시 에러 문구 출력 "[ERROR]" 로 시작

### 도메인 모델
- domain package
  - Lotto (불변)
    - 랜덤 숫자로 티켓 생성
    - 오름차순 정렬
  - LottoNumber
    - 불변 제약 검증(6개, 1~45 범위, 중복 없음)
  - WinningNumbers
    - 당첨 번호 집합 + 보너스
    - 유효성 (6개, 1~45 범위, 중복 금지, 보너스와 중복 금지)
  - Rank (enum)
    - 등수 규칙과 상금 소유
    - 등수 판정
  - LottoResult
    - 집계 결과 저장

- view package
  - InputView
    - 구입 금액 입력
    - 당첨 번호 입력
    - 보너스 번호 입력
    - 각 입력에 대한 검증
    - 번호 split
  - OutputView
    - 발행한 로또 출력
    - 당첨 결과 출력
    - 수익률 출력
- exception package
  - ErrorCode

- controller package
  - LottoController
